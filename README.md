# Vemar Importados

Sitio web de Vemar Importados — joyería importada, Asunción, Paraguay.

Sitio estático (HTML + JS). `index.html` es la página; `support.js` es el runtime; las imágenes están en `images/`, `uploads/` y `Colecciones/`.

## Deploy en Vercel
Es un sitio estático, sin build. Vercel sirve `index.html` en la raíz automáticamente (framework: **Other** / Static).
